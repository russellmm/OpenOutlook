## Gotchas learned
- **Never rewrite source files with Windows PowerShell 5.1 `Get-Content`/`Set-Content`**: it reads UTF-8 as ANSI and turns the ellipsis character into mojibake (it happened once; repaired and compared against the backup). Use Python with explicit encodings.
- **Python inside a bash heredoc eats backslashes** (`\r\n` and `\\n` end up as real newlines inside C# strings and break the build). Write scripts with the Write tool and run them with `python -I`, or use the Edit tool.
- The mailbox copies (hidden PSTs under `%LOCALAPPDATA%\OpenOutlook\Mail`) are not offered as copy/move destinations (the sync would overwrite them). The harness's `PstEngineFactory.Open` cannot open a second handle on a file the window holds for writing: tests read through the window's own store (`_stores`).
- `FolderPickItem.Tag` of the transfer picker carries `PstTarget` / `MicrosoftTarget` / `GmailTarget` (and `*PickRoot` for the unselectable store rows); the headless tests reach them by reflection.
